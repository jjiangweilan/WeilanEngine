Main: 引擎入口，处理所有的引擎生命周期和执行
Tools - 独立于引擎的可执行程序
Editor: GameEditor
Engine:
- **Core** - 引擎核心层
	1. 管理引擎对象生命周期
	2. 内存管理
	3. 性能检测 Profiler
- **Driver** - 最底层的独立运行库
	1. GfxDriver
	2. Physics
	3. Audio
- **MiddleLayer**
	1. EngineCommand
	2. EngineDebug
	3. SystemInfo
	4. EngineInternalResources
	5. FrameContext
- **Runtime**
	- **CommonObject** - 所有的通用引擎对象
		- Scene, GameObject, Component, Material, Mesh, Texture
	- **System** - 引擎功能
		1. AssetDatabase
		2. SceneManager
		3. Event
		4. Input
		5. Rendering
			1. RenderingScene
			2. RenderPipeline
		6. ScriptingBackend
		7. Physics
			1. PhysicsScene
	- **Modules** - 引擎具体扩展功能
		1. Foliage
		2. Ocean
		3. Terrain
		4. Volumetric Cloud
- **Game** - 偏向业务层的可快速迭代区
	1. Components
	2. Inventory
- Library - 编程相关功能，(Libs)
	1. Platform - 操作系统扩展
	2. Math
		1. Geometry
- ThirdParty - 引擎内置的第三方库
- Shaders - Shader 文件
- CodeGen - 工具生成代码

Core-> Driver -> MiddleLayer-> Runtime -> Game -> Editor -> Main
